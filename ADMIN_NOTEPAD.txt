[🔒 STEALTH ADMIN PANEL OPENING SHORTCUTS]
Since public admin links have been removed from the customer storefront for 
security, authorized operators can open the Admin Portal using any of these methods:

1. KEYBOARD HOTKEY (STEALTH SHORTCUT):
   -----------------------------------------------------------------------------
   • On Mac:             ⌘ Command + Shift + A
   • On Windows / Linux: Ctrl + Shift + A
   -----------------------------------------------------------------------------
   Pressing this shortcut anywhere on the customer storefront immediately 
   triggers the secure Admin Login Modal!

2. HOW TO CUSTOMIZE / CHANGE THE HOTKEY:
   -----------------------------------------------------------------------------
   You can change this shortcut anytime directly from inside the Admin Studio!
   • Open Admin Studio -> Look at the top-right header -> Click "Hotkey: Shift+A"
   • Choose your preferred modifier (Cmd/Ctrl+Shift, Cmd/Ctrl+Alt, Alt+Shift)
   • Select any trigger letter (A, K, M, X, P, S, Z or custom letter/digit)
   • Click "Save Hotkey" — it updates instantly and persists in your browser!

3. DIRECT SECRET URL PARAMETER:
   -----------------------------------------------------------------------------
   • URL: http://localhost:3000/?admin=1
   (Visiting this URL in any browser tab immediately pops open the Admin Login)

4. ADMIN LOGIN CREDENTIALS:
