===================================================================
      PrintFlow Admin Studio v2.0 - macOS Native App
===================================================================

INSTALLATION INSTRUCTIONS:
1. Drag "PrintFlow Admin Studio.app" into the "Applications" folder shortcut.
2. Open Applications (or press Cmd+Space and search "PrintFlow Admin Studio").
3. Launch the app!

FEATURES:
- Full Control of PrintFlow POD eCommerce & Storefront.
- Real-time Admin Control Panel, Product Manager & Order Tracker.
- Seamless automatic switching between Local Dev (127.0.0.1:3000) and Cloud Live.
- Dedicated macOS Native Window with Toolbar & Keyboard Shortcuts (Cmd+R, Cmd+1, Cmd+2).
